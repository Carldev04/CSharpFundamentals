Dobro došli u moj repozitorij posvećen učenju i savladavanju osnova **C#** programskog jezika i **.NET** platforme! Ovaj repozitorij je strukturiran kronološki kroz 17 lekcija — od osnovne sintakse i tipova podataka, preko kontrole toka i petlji, pa sve do objektno orijentiranog programiranja (OOP).

---

## 📚 Popis lekcija i struktura projekta

Sve lekcije nalaze se unutar direktorija `cSharpFundamentals` i organizirane su po tematskim cjelinama:

| # | Mapa (Lekcija) | Obuhvaćeni koncepti i opis |
| :--- | :--- | :--- |
| **01** | [`01_komentari`](./cSharpFundamentals/01_komentari) | Jednolinijski (`//`), višelinijski (`/* */`) i XML dokumentacijski komentari |
| **02** | [`02_Variables`](./cSharpFundamentals/02_Variables) | Deklaracija, inicijalizacija varijabli i rad s konstantama (`const`) |
| **03** | [`03_DataTypes`](./cSharpFundamentals/03_DataTypes) | Primitivni tipovi podataka (`int`, `double`, `char`, `bool`, `string`) i memorijski opseg |
| **04** | [`04_Casting`](./cSharpFundamentals/04_Casting) | Implicitna i eksplicitna pretvorba tipova (Type Casting) te `Convert` metode |
| **05** | [`05_UserInput`](./cSharpFundamentals/05_UserInput) | Čitanje korisničkog unosa iz konzole (`Console.ReadLine()`) i parsiranje podataka |
| **06** | [`06_Operators`](./cSharpFundamentals/06_Operators) | Aritmetički, relacijski (usporedni), logički operatori i operatori pridruživanja |
| **07** | [`07_Math`](./cSharpFundamentals/07_Math) | Korištenje ugrađene `Math` klase (`Math.Max`, `Math.Min`, `Math.Sqrt`, `Math.Abs`, `Math.Round`) |
| **08** | [`08_StringExamples`](./cSharpFundamentals/08_StringExamples) | Manipulacija stringovima, konkatenacija, interpolacija (`$""`), indeksiranje i metode |
| **09** | [`09_Booleans`](./cSharpFundamentals/09_Booleans) | Logičke vrijednosti (`true` / `false`) i evaluacija logičkih izraza |
| **10** | [`10_IfElse`](./cSharpFundamentals/10_IfElse) | Uvjetno grananje (`if`, `else if`, `else`) i ternarni operator (`? :`) |
| **11** | [`11_switch`](./cSharpFundamentals/11_switch) | Višestruko grananje pomoću `switch-case` blokova i `default` slučaja |
| **12** | [`12_whilepetlje`](./cSharpFundamentals/12_whilepetlje) | Iteracija s uvjetom na početku (`while`) i na kraju bloka (`do-while`) |
| **13** | [`13_forpetlja`](./cSharpFundamentals/13_forpetlja) | Standardna `for` petlja, ugniježđene petlje i iteracija kroz kolekcije pomoću `foreach` |
| **14** | [`14_break_continue`](./cSharpFundamentals/14_break_continue) | Kontrola izvođenja petlji — prijevremeni izlazak (`break`) i preskakanje iteracije (`continue`) |
| **15** | [`15_Nizovi`](./cSharpFundamentals/15_Nizovi) | Jednodimenzionalni i višedimenzionalni nizovi (Arrays), pristup elementima i sortiranje |
| **16** | [`16_Metode`](./cSharpFundamentals/16_Metode) | Definiranje i pozivanje metoda, parametri, povratne vrijednosti (`return`) i *Method Overloading* |
| **17** | [`17_OOP`](./cSharpFundamentals/17_OOP) | Osnove objektno orijentiranog programiranja (Klase, Objekti, Polja, Svojstva, Konstruktori) |
